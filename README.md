# Self Compass

Self Compass は、日々の状態・状態の波・思考メモ・If-Thenプラン・セルフケア・相談前まとめを記録できるセルフケア記録アプリです。

医療アプリではなく、自分の状態をふり返ったり、相談時の材料を整理したりするための記録補助ツールです。

## 目的

- 自分の状態を記録する
- 状態の波やきっかけをふり返る
- 思考のくせに気づく
- If-Thenプランで小さな行動を決める
- セルフケアを試す
- 医師・カウンセラー・支援者・AI相談の前に内容を整理する

## データ保存

- 記録はブラウザの `localStorage` に保存されます。
- 共有URLを開いた人同士で記録が共有されるわけではありません。
- ブラウザデータ削除や端末変更で記録が消える可能性があります。
- 必要に応じて、アプリ内のデータ管理画面からJSONバックアップを保存してください。
- このアプリは外部サーバーへ記録を送信しない設計です。ただし、利用環境によってはブラウザや端末側の管理に依存します。

## デモモード

デモモードでは、架空の1ヶ月分サンプルデータを使って、グラフ・リングビュー・ふり返りコメントの見え方を確認できます。

- サンプルデータは実データと区別できます。
- サンプルデータは架空データです。
- 必要に応じて、データ管理画面からサンプルデータだけ削除できます。

## 注意事項

Self Compass は診断や治療を行うものではありません。記録は、自分の状態をふり返ったり、医師・カウンセラー・支援者に相談するときの参考情報として利用してください。

気になる状態が続く場合は、医師・カウンセラー・専門家に相談してください。

命に関わる可能性があると感じるときや、一人で抱えるのが難しいと感じるときは、すぐに119番、近くの救急外来、または信頼できる人に連絡してください。
